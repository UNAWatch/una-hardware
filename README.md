## Summary

This repo contains the hardware design files for UNA watch, enabling users to debug their own hardware. 

## Contents

una-watch

	- electronics
	
		Schematic, assembly and fabrication drawings for each of the 6 PCBs in UNA Watch:
	
		UNAaltimeter_MS5837
		UNAbody_PAH8316
		UNAcore
		UNAlink_AG3335M
		UNAlink_BLUENRG2
		UNAview_LS012
	
	- mechanical
	
		.stp files for each mechanical part
